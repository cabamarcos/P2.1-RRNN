# Entrega original

`P2.1_RRNN_original.ipynb` conserva el análisis académico original de **Pablo Hidalgo
Delgado y Marcos Caballero Cortés**. Incluye salidas y configuraciones de aquella
entrega; utiliza APIs antiguas y no forma parte de las comprobaciones actuales.

Los cuadernos de la raíz y el paquete `transport` contienen la versión ejecutable
actual, con partición por trayectorias, normalización ajustada solo sobre train,
selección con validación e inferencia desde un modelo guardado.
